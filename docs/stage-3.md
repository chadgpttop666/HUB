# Этап 3: приложения от нейросети и свои темы

Критерий перехода к этапу 4 (из диздока): **календарь от нейросети работает без правок хаба**.

## Что сделано

**`APP_SPEC.md`** (в корне) — файл, который прикладывается к запросу «сделай мне приложение для…»: формат папки и манифеста, весь Hub API с примерами, токены темы, компоненты `hub-*` с разметкой, все допустимые значки, запреты и шаблон, который заведомо работает. Файл **собирается** скриптом `node scripts/app-spec.mjs` из `docs/app-spec.template.md`, дизайн-системы и `templates/app` — поэтому списки токенов и значков всегда настоящие; CI проверяет, что он не устарел.

**Установка из папки или zip:**

- перетащить папку или архив в окно хаба (или «Настройки → Приложения → Установить из папки / Из zip»);
- хаб читает пакет (одна общая папка верхнего уровня в архиве допускается) и показывает: имя, версию, «было → станет» при обновлении, что приложение просит (свои данные, приём из корзины, карточка, сеть — с тегом), чего не получит никогда;
- **ошибки** (нет `id`/`name`, нет страницы, не-https адрес сети…) — не ставит и перечисляет словами;
- **предупреждения** по правилам оформления (свои цвета, свои шрифты, внешние скрипты без заявки) — ставит, но показывает, что поправить;
- установленное лежит в данных хаба (`hub/apps/<id>/…`), поэтому **зашифровано и само приезжает на телефон**; удалить можно с данными или без.

Темы ставятся так же: папка или zip с `theme.json` (+ фото).

**Свои темы из фото** (Настройки → Тема → «Новая тема из фото») — по правилам `design-system/01-themes.md`: фото размывается как фон хаба; основа тёмная или светлая — по медиане яркости; сила вуали для шапки, середины, низа и колонки входа — наименьшая, при которой текст читается на худшем пикселе зоны (4.5:1, часы 3:1). Акцент — один из четырёх проверенных наборов. Положение фото по высоте и своё приветствие — тоже. Тема синхронизируется на телефон.

**Календарь** (`apps/calendar`) — написан строго по `APP_SPEC.md`, без единой правки хаба: месяц и день, события по ключу на каждое, приём из корзины с разбором даты по-русски («завтра в 16:00 консультация», «25 ноября доклад», «в пятницу встреча в 9», «12.01 экзамен»), «Без даты» — для мыслей без даты, карточка на «Сегодня» («2 события сегодня · ближайшее: 16:00 …» / «Сегодня событий нет · завтра — …»).

**Исправления по первому запуску на Windows:** нет окна консоли рядом с хабом; вход в Google понимает новый вид ответа rclone (base64); вместо белой страницы rclone — своя «Вход выполнен»; своя кнопка «показать пароль»; свой заголовок окна в цвет темы; боковая панель и строка ввода прячутся кнопками «Панель» и «Строка ввода» в заголовке (по умолчанию спрятаны, `Ctrl+Пробел` показывает строку на время ввода).

## Честно о критерии

Календарь написал я — тот же, кто писал хаб, хотя и строго по `APP_SPEC.md` и без правок хаба. Настоящая проверка критерия — отдать `APP_SPEC.md` другой нейросети (или новому чату) с просьбой «сделай мне приложение для…» и поставить результат перетаскиванием. Если что-то не сработает с первого раза — это повод поправить `APP_SPEC.md`, а не хаб.

## Что не проверено и где я не уверен

- **Перетаскивание файлов в окно на Windows** — события Tauri `drag-drop` проверены только по документации, вживую — нет (уверенность средняя-высокая). Кнопки «Установить из папки / Из zip» — запасной путь.
- **Своя тема на экране входа**: до ввода пароля фото своей темы зашифровано, поэтому вход показывает встроенную тему той же основы.
- Проверка оформления при установке — по тексту файлов (поиск `#hex`, `rgb(`, `font-family`, внешних адресов), а не по отрисовке: возможны и пропуски, и лишние замечания.
- На телефоне установки нет — приложения ставятся на ПК и приезжают синхронизацией (как в макетах).
