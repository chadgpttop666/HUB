# Hub API (этап 1)

Это всё, что видит приложение внутри хаба. Основа будущего `APP_SPEC.md` (этап 3): там к этому добавятся правила оформления из `design-system/03-apps.md` и шаблон приложения.

## Приложение — это папка

```
apps/<id>/
  manifest.json
  index.html
  icon.svg        (необязательно)
```

`<id>` — строчные латинские буквы, цифры, `-`, `_`, `.`; не `hub`.

```json
{
  "id": "repetition",
  "name": "Повторение",
  "version": "2.1.0",
  "description": "Теории, интервальное повторение (FSRS), план и дневник",
  "icon": "layers",
  "entry": "index.html",
  "card": true,
  "accepts": [{ "type": "text", "label": "Заготовка теории" }],
  "permissions": { "network": [] }
}
```

| поле | что значит |
| --- | --- |
| `icon` | имя значка Lucide из `HubUI.iconNames` (панель приложений, карточка, разбор корзины) |
| `entry` | страница приложения, по умолчанию `index.html` |
| `card` | приложение рисует карточку на «Сегодня» — хаб запускает его в фоне при старте |
| `accepts` | что приложение принимает из корзины; каждая строка — плитка «Куда перенести» при разборе. Приложение с `accepts` тоже запускается в фоне |
| `permissions.network` | адреса `https://…`, куда приложению можно ходить (`connect-src`). Пусто — сети нет |

Где лежат приложения: встроенные — в `apps/` репозитория (попадают внутрь хаба при сборке); свои — в папке `apps` рядом с данными хаба (путь — в «Настройках»). Своё приложение с тем же `id` заменяет встроенное. Установка перетаскиванием папки или zip — этап 3.

## Что хаб делает со страницей

Хаб читает `index.html` и открывает его в `<iframe sandbox="allow-scripts allow-forms allow-downloads allow-modals allow-pointer-lock">` без `allow-same-origin`. В начало `<head>` он вставляет:

1. `Content-Security-Policy`: скрипты, стили, шрифты и картинки — только из папки приложения и из хаба (`'unsafe-inline'` разрешён), `connect-src` — только своя папка и адреса из `permissions.network`, всё остальное закрыто;
2. `<base href>` на папку приложения — относительные ссылки (`icon.svg`, `app.js`) работают;
3. `tokens.css`, `hub.css` (`hub-*`), `app.css` (поля страницы), `hub-ui.js` (`window.HubUI`);
4. все данные приложения и `hub-app.js` (`window.hub`).

На `<html>` стоят `data-theme` (`dark` / `light` / `solid`) и `data-hub-embedded`. Фон страницы прозрачный — под ней фото темы и стекло хаба.

Что приложению **недоступно**: страница хаба и другие приложения (`parent.document` → `SecurityError`), ядро Tauri (`window.__TAURI__` нет), интернет (кроме заявленного), файлы других приложений. Проверяется приложением `tools/sandbox-probe`.

## `hub.data` — данные приложения

Ключ — строка до 400 знаков, `/` делит его на папки. Значение — любое JSON-значение или `Blob`.

```js
await hub.data.set("cards/abc", { q: "Вопрос", a: "Ответ" });
const card = await hub.data.get("cards/abc");      // undefined, если нет
await hub.data.remove("cards/abc");
const keys = await hub.data.keys("cards/");         // ["cards/…", …]
await hub.data.set("audio/1", file);                // Blob / File
const blob = await hub.data.get("audio/1");         // Blob
const v = hub.data.peek("settings");                // синхронно, только JSON
```

- Все JSON-данные приложения приходят при запуске вместе со страницей: `get` и `peek` читают из памяти, `set` сразу меняет память и отправляет запись в хаб. Записи по одному приложению сохраняются строго по очереди.
- На диске: `<данные>/<id>/<ключ>.json` (`.bin` + `.type` для Blob). Заглавные буквы и всё, кроме `a-z 0-9 - _ .`, экранируются `%XX` — так имена не зависят от регистра на Windows. Поэтому ключи лучше писать строчными.
- Ошибку записи хаб показывает уведомлением; промис `set` при этом отклоняется.

## `hub.inbox` — корзина

```js
await hub.inbox.add("Купить книгу #чтение");        // положить в корзину (метки из #слов)

hub.inbox.onItem(async (item, { type, label }) => {
  // item: { id, text, created, device, tags, source? }
  await saveSomewhere(item.text);
  // вернуть false или бросить ошибку — элемент вернётся в корзину
});
```

Как это работает: при разборе пользователь переносит элемент в приложение → элемент уходит из корзины в очередь доставки (`data/hub/deliveries.json`) → через 4,5 с (столько живёт «Отменить») хаб передаёт его в `onItem`. Если приложение закрыто, хаб запускает его в фоне. Элемент удаляется из очереди только после ответа обработчика.

## `hub.today` — карточка на «Сегодня»

Приложение отдаёт данные, хаб рисует карточку сам (компонент «Карточка приложения»).

```js
hub.today.set({
  main: "12 тем к повторению",                    // главная строка, с числом
  note: "серия 5 дн. · помню 87%",                 // одна строка пояснения
  action: { label: "Начать", open: "rep" },       // кнопка; open вернётся в onAction
});
hub.today.set({ main: "Всё повторено", note: "завтра — 14 тем", done: true });  // тихая карточка
hub.today.set({ main: "Осталось 2 из 4", list: [{ text: "балкон", done: true }, { text: "карточки", done: false }] });
hub.today.onAction(a => openSection(a.open));
```

Одинаковая карточка повторно не отправляется — `set` можно вызывать после каждой отрисовки.

## `hub.theme`, `hub.notify`

```js
hub.theme.get();                       // { id: "forest", name: "Лес", base: "dark", tokens: {…} }
hub.theme.onChange(t => redrawChart());  // атрибуты и переменные хаб меняет сам
await hub.notify("Блок закончился", { title: "Учебный блок" });
```

`notify` — уведомление внутри хаба, а если окно хаба свёрнуто или не в фокусе — системное.

## Совместимость со старыми страницами

Для переноса готовых страниц (как `repetition.html`) хаб подменяет браузерные API:

| API | что делает в хабе |
| --- | --- |
| `localStorage` | синхронный, данные в `localstorage/<ключ>`; точный JSON ложится на диск разобранным, остальное — строкой; чтение возвращает ровно записанную строку |
| `sessionStorage` | в памяти, до перезапуска страницы |
| `indexedDB` | подмножество: `open` (с `onupgradeneeded`), `createObjectStore` (`keyPath`, `autoIncrement`), `put`, `add`, `get`, `getAll`, `getAllKeys`, `getKey`, `count`, `delete`, `clear`, события `success` / `error` / `complete`. Поля-`Blob` верхнего уровня хранятся отдельными файлами. **Нет** курсоров и индексов. `getAll` отдаёт Blob больше 8 МБ пустой заглушкой (`__hubLazy`), полностью — через `get` |
| `Notification` | `permission` всегда `"granted"`, `new Notification(t, {body})` → `hub.notify` |
| `navigator.storage.persist()` | всегда `true` |

## Клавиши хаба

Пока фокус в приложении, `hub-app.js` перехватывает и передаёт хабу: `Ctrl+Пробел` (к строке ввода), `Alt+1…9` (приложение по номеру), `Ctrl+K`, `Ctrl+L` (зарезервированы на следующие этапы). Приложению их не занимать.
