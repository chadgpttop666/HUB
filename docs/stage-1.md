# Этап 1: оболочка, корзина, повторение

Критерий перехода к этапу 2 (из диздока): **две недели реально пользуюсь корзиной и повторением**. Код ниже — только условие, чтобы начать этот отсчёт.

## Что сделано

**Оболочка** (`ui/`), собрана из готовых компонентов дизайн-системы, направление А:

- «Сегодня»: приветствие и дата, строка «Мысль в корзину…» с курсором, карточки — «Корзина» и по одной от каждого приложения.
- Строка ввода: `Enter` — в корзину, `#слово` — метка, `Ctrl+Z` — отменить, подсказка «В корзине — N неразобранных» на 2,6 с, карточка корзины вспыхивает. Компактная строка в шапке оболочки приложения.
- Разбор корзины: элемент крупно, плитки «Куда перенести» из `accepts` манифестов с цифрами, «Отложить» (меню: вечер / завтра утром / через неделю / своя дата), «Удалить» с «Отменить», листание, итог пустой корзины.
- Оболочка приложения: панель слева (Сегодня, Корзина с числом, приложения, Настройки), приложение — во всю область стекла.
- Настройки: три темы из дизайн-системы (Лес, Туман, Без фото) — перекрашивают хаб и приложения сразу; список приложений; папка данных; клавиши.
- Клавиши: `Ctrl+Alt+Пробел` из любой программы, `Ctrl+Пробел` и `/`, `Alt+1…9`; хаб получает их и тогда, когда фокус внутри приложения.

**Песочница и Hub API** (`ui/js/host.js`, `runtime/hub-app.js`) — описаны в [hub-api.md](hub-api.md): данные, корзина, карточка «Сегодня», тема, уведомления; подмены `localStorage`, `indexedDB`, `Notification` для старых страниц.

**Ядро** (`src-tauri/`): файловое хранилище «ключ — файл» с атомарной записью, протокол `hubapp://` (страницы приложений и дизайн-система), список встроенных и своих приложений, системные уведомления, один экземпляр хаба, глобальная клавиша.

**«Повторение»** (`apps/repetition/`): `repetition.html` почти без изменений логики.

- Стили переведены на токены темы: ни одного своего цвета и шрифта, Google Fonts убран (его всё равно закрывает CSP).
- В конец скрипта добавлен блок «Внутри Хаба»: карточка на «Сегодня» («N тем к повторению» / «Всё повторено»), кнопка «Начать» открывает повторение, элемент корзины становится заготовкой на стадии «услышал» (первая строка — название, остальное — конспект, `#метки` вырезаются).
- Хранилище не тронуто: `localStorage` и `indexedDB` подменяет хаб. Ответ на вопрос диздока «получится ли обойтись парой строк» — **да для данных** (ноль строк в самом приложении), но стили пришлось переписать (~60 правил), а для `indexedDB` (фото и ролики) понадобилась подмена побольше.

## Что не проверено и где я не уверен

- **Windows (WebView2) вживую не запускался** — только сборка в GitHub Actions. Уверенность средняя, что всё работает так же, как в WebKitGTK и Chromium. Первым делом на Windows:
  1. скопировать `tools/sandbox-probe` в папку `apps` рядом с данными (`%APPDATA%\local.hub.desktop\apps\sandbox-probe`), перезапустить хаб — на «Сегодня» должна быть карточка «Все 12 проверок в порядке». Главное — что Tauri не подмешивает `__TAURI__` в iframe на WebView2 (уверенность средняя-высокая, что не подмешивает);
  2. «Экспорт» в «Повторении» — куда WebView2 сохранит архив (по умолчанию, кажется, спрашивает или кладёт в «Загрузки»; уверенность низкая);
  3. `Ctrl+Alt+Пробел` — не занят ли другой программой (если занят, хаб пишет об этом в консоль и работает без неё);
  4. системные уведомления таймера «Повторения», когда хаб свёрнут.
- **Ролики в «Плеере»** хранятся файлами через ядро, но каждый целиком проходит через память при добавлении и включении. Для роликов на сотни мегабайт может быть медленно (не проверено на больших файлах).
- **Удаление через «Отменить» после переноса** работает 4,5 с; после этого элемент уже у приложения, и отменять надо там.
- Сложные места `indexedDB` (курсоры, индексы, `versionchange` при открытой базе) не поддержаны — «Повторению» они не нужны, другим старым страницам могут понадобиться.
- Шрифты в «Повторении» теперь Manrope, но начертания (жирные 700–800) остались свои — по брендбуку жирного быть не должно. Полная перерисовка на `hub-*` (как в `design-system/components/ExampleApp`) — отдельная работа.

## Чего на этапе 1 нет — по плану

- Пароль, экран входа, шифрование базы, ключ восстановления — этап 2 (вместе с синхронизацией).
- Синхронизация, Drive, телефон — этап 2.
- Установка приложений перетаскиванием, `APP_SPEC.md`, календарь — этап 3. Сейчас своё приложение можно положить папкой в `apps` рядом с данными.
- Приветственный экран, автозапуск, редактор тем, мини-окно ввода поверх программ — этап 4. Сейчас `Ctrl+Alt+Пробел` поднимает окно хаба.
- `Ctrl+K` (командная строка) и `Ctrl+L` (замок) — клавиши уже зарезервированы, сами функции — позже.

## Заметки для этапа 2

- Данные хаба уже лежат «по файлам» (`data/<пространство>/<ключ>.json`) — так, как диздок предлагает синхронизировать через rclone bisync.
- Корзина и доставки сейчас — по одному файлу (`data/hub/inbox.json`, `deliveries.json`). Для двух устройств их надо перевести на журналы `changes-pc` / `changes-phone`, как в диздоке.
- Имена файлов не зависят от регистра (заглавные экранируются), поэтому папка переживёт перенос между Windows и Android.
