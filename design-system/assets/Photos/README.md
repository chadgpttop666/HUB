# Фото тем

- `forest.jpg` — тема «Лес» (тёмная, основная): лес в тумане на рассвете. Из прототипа, 1470×840, со скриншота; автор и лицензия неизвестны — нужна замена оригиналом или свободным фото.
- `mist.jpg` — тема «Туман» (светлая): временная заглушка, сгенерирована, без ограничений. Заменить настоящим светлым фото.

Фото не правят: читаемость дают размытие и вуаль, которые считаются по фото (раздел «Темы»). Те же файлы лежат в `themes/<тема>/photo.jpg` рядом с `theme.json`.
