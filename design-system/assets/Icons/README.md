# Иконки

Подмножество Lucide 1.64.0 (лицензия ISC, `licenses/Lucide-ISC.txt`), файлы без изменений. Линия в файлах — 2; в интерфейсе hub-ui.js рисует их с линией 1.6 и цветом `currentColor`, поэтому в `<img>` они чёрные — так их показывать не нужно.

Те же иконки встроены в hub-ui.js: `<i data-icon="имя"></i>` или `HubUI.icon("имя")`. Недостающую берут из Lucide того же стиля.
