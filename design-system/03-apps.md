# Правила для приложений

Этот раздел переносится в `APP_SPEC.md`: по нему нейросеть пишет приложения для хаба. Цель — чтобы десять приложений выглядели как одно.

## Что приложение получает от хаба

Хаб сам подставляет в страницу приложения переменные текущей темы и стили `t-*`, `hub.css`, `hub-ui.js` и шрифты, а на `<html>` ставит `data-theme` и `data-hub-embedded`. Приложение ничего из этого не подключает и не грузит из интернета. Механизм подстановки проверяется на первом этапе (уверенность средняя): страницы приложений открываются в песочнице, и размытие стекла внутри неё не видит фото хаба. Поэтому фото уже размыто под приложением, а стекло в приложении — просто полупрозрачная поверхность.

## Обязательные правила

1. Цвет, шрифт, размер шрифта, толщина, скругление, размытие и длительность — только `var(--…)` из токенов или готовые классы. Никаких `#hex`, `rgb()`, названий цветов и своих шрифтов.
2. Только компоненты `hub-*`. Нужного нет — не рисовать своё, а попросить добавить компонент в hub.css.
3. Фон страницы не задавать: под приложением уже фото, вуаль и стекло области приложения.
4. Иконки — только `<i data-icon="…">` или `HubUI.icon()` из Lucide; без эмодзи.
5. Состояния — атрибутами: `disabled`, `aria-invalid`, `aria-selected`, `aria-pressed`, `aria-busy`, `aria-current`.
6. Всё делается с клавиатуры; фокус виден; горячие клавиши подписаны `hub-kbd`. Не перехватывать клавиши хаба: Ctrl+Пробел, Ctrl K, Alt+1…9, Ctrl L.
7. Одна основная кнопка на экран. Опасное действие — `hub-btn--danger`, удаление одного элемента — сразу и с «Отменить» в уведомлении.
8. Тексты — по разделу «Тексты» брендбука: русский, коротко, глагол на кнопке, правильные формы чисел (`HubUI.plural`).
9. Своя у приложения — только раскладка (сетка, колонки) и тексты.

## На телефоне

Одно и то же приложение открывается на ПК и на телефоне, поэтому:

- раскладка перестраивается до одной колонки при ширине до 600px (сетка через `grid-template-columns: repeat(auto-fit, minmax(…, 1fr))` или медиазапрос);
- всё, что нажимают, — от 48px (`hub-btn--lg`, `hub-input--lg`), главные действия — внизу экрана;
- ничего не прячется до наведения мышью; горячие клавиши — подсказка, а не единственный путь;
- верхнюю строку (`hub-appbar` со стрелкой назад) рисует хаб, приложение начинает со своего содержимого;
- таблицы на узком экране превращаются в списки `hub-row`.

## Каркас экрана приложения

```html
<!doctype html>
<html lang="ru">
<body>
  <header style="display:flex;align-items:flex-end;justify-content:space-between;gap:var(--space-4)">
    <div>
      <h1 class="hub-page-title">Повторение</h1>
      <p class="hub-muted" style="margin:var(--space-1) 0 0">12 карточек к сроку</p>
    </div>
    <button class="hub-btn" type="button"><i data-icon="plus"></i>Карточка</button>
  </header>

  <div role="tablist" class="hub-tabs" data-hub-tabs style="margin-top:var(--space-5)">
    <button class="hub-tab" role="tab" aria-selected="true" aria-controls="p1">Сессия</button>
    <button class="hub-tab" role="tab" aria-selected="false" aria-controls="p2" tabindex="-1">Статистика</button>
  </div>

  <section id="p1" role="tabpanel" style="margin-top:var(--space-6)">
    <article class="hub-glass" style="padding:var(--space-8)">
      <p class="t-display" style="margin:0">Вопрос карточки</p>
      <div class="hub-btn-row" style="margin-top:var(--space-8)">
        <button class="hub-btn hub-btn--primary hub-btn--lg" type="button">Показать ответ <kbd class="hub-kbd">Пробел</kbd></button>
      </div>
    </article>
  </section>
  <section id="p2" role="tabpanel" hidden></section>
</body>
</html>
```

## Карточка на «Сегодня»

Приложение отдаёт хабу данные, а не разметку; хаб рисует их одним шаблоном (компонент «Карточка приложения»). Предлагаемая форма (уточняется вместе с Hub API):

```json
{
  "main": "12 карточек к сроку",
  "note": "2 темы просели: логика, право",
  "action": { "label": "Начать", "open": "session" }
}
```

или вместо `action` — список до 4 пунктов: `"list": [{ "text": "балкон", "done": true }]`. Название и иконка берутся из манифеста. Когда всё сделано — `"done": true`, и карточка становится тихой.

## Перед установкой проверить

- В файлах приложения нет ни одного цвета, шрифта и размера шрифта в обход токенов.
- Нет `<link>` и `<script>` на внешние адреса.
- Вход, разбор, пустое состояние, загрузка и ошибка нарисованы готовыми компонентами.
- Приложение выглядит правильно во всех трёх темах: `dark`, `light`, `solid` — и на ширине 390px.
- Всё проходится Tab и Enter, фокус виден везде.
