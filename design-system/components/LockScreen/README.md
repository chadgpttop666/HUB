# Экран входа

Первое, что видно при включении компьютера: фото темы, время, дата и приветствие; любая клавиша проявляет поле пароля.

Состояния:

1. **Заставка** (`data-scene="lock"`) — фото чёткое, за колонкой пятно вуали `scrim-lock`. Часы `t-clock`, дата `t-date` `text-muted`, приветствие `t-greeting` с тонкой линией `line` под ним. Внизу подсказка «Нажмите любую клавишу», цвет «дышит» между `text-muted` и `text` раз в `duration-breathe`. Кнопки «Войти» нет.
2. **Пароль** (`pass`) — любая клавиша или клик: фото размывается до `blur-lock`, часы уменьшаются, появляется поле-линия с фокусом; первый набранный символ уже в поле. Подсказка: «Enter войти · Esc назад». 30 с без ввода — назад к заставке.
3. **Неверный пароль** — линия `danger`, поле вздрагивает (`hub-shake`, без него при «уменьшить движение»), сообщение со значком, текст выделен, чтобы набрать заново. Под ним тихая ссылка «Войти ключом восстановления».
4. **Caps Lock** — предупреждение `warning` со значком, как только нажата клавиша, ещё до отправки.
5. **Английская раскладка** — слева в поле тег «EN»; если пароль в русской раскладке совпал бы, сообщение говорит об этом прямо.
6. **Переход к «Сегодня»** — раскадровка с длительностями; живой вариант — карточка «Живой поток».

Что даёт хаб: имя, текст приветствия из темы (по умолчанию по времени суток: «Доброе утро / день / вечер / ночи»), номер дня. Приветствие — без восклицательного знака.
