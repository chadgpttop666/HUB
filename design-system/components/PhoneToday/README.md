# Телефон · «Сегодня» и приложения

«Сегодня» на телефоне — те же строка ввода и карточки, только столбиком и с нижней панелью разделов.

- Шапка `hub-phone-head`: приветствие Jost light 22px, дата `text-muted`, справа статус синхронизации значком (`hub-sync--icon`).
- Строка ввода `hub-capture--phone`: кнопка отправки — круглая со стрелкой вверх, 44px.
- Карточки `hub-card--compact`, по одной в ряд, одна строка на главное и одна на пояснение; карточка со списком — до 4 пунктов.
- **Нижняя панель** `hub-navbar` (80px, по канону Android): «Сегодня», «Корзина» с числом, «Приложения», «Настройки». Текущий раздел — подложка `accent-soft` под значком. Корзина открывает разбор.
- **Приложения** — сетка по 3: значок `hub-app-icon` и название. Ставятся приложения на ПК и приезжают на телефон с синхронизацией (как в диздоке).
- **Открытое приложение** — нижняя панель прячется, сверху `hub-appbar`: «назад», название, меню «ещё». Системный жест «назад» делает то же, что стрелка. Главные действия — внизу, под большим пальцем: оценки 2×2 высотой 60px.
- Все цели касания — от 48px.
