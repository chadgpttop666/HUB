# Загрузка

Как показать ожидание: кружок — для действия, скелет — для содержимого, полоса — для долгого процесса.

```html
<span class="hub-spinner" role="status" aria-label="Загрузка"></span>
<button class="hub-btn hub-btn--primary" aria-busy="true">Устанавливаю</button>
<div class="hub-skeleton hub-skeleton--title"></div>
<progress class="hub-progress" aria-label="Синхронизация"></progress>
```

- Меньше 300 мс — ничего не показывать. До 2 секунд — кружок или `aria-busy` на кнопке. Содержимое экрана или карточки — скелет той же формы, что будет. Дольше и с понятным концом — полоса `hub-progress` с числом.
- Кружок: дорожка `line-soft`, дуга `accent`. При «уменьшить движение» не вращается, а мягко мерцает; скелет тоже без бегущего блика.
- Подпись — что именно происходит: «Загружаю темы…», а не «Подождите».
