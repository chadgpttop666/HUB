# Строка быстрого ввода

Главный элемент хаба: мысль падает в корзину за пару секунд — набрал, Enter, дальше.

```html
<form class="hub-capture">
  <div class="hub-capture__bar">
    <i data-icon="lightbulb" class="hub-capture__icon"></i>
    <input class="hub-capture__input" placeholder="Мысль в корзину…" aria-label="Мысль в корзину">
    <button class="hub-capture__send" type="submit" disabled>В корзину</button>
  </div>
  <p class="hub-capture__note" aria-live="polite">Enter — сохранить, разобрать можно потом</p>
</form>
```

- После входа курсор уже здесь. С любого места «Сегодня» — `/` или `Ctrl+Пробел`; из любой программы — глобальная горячая клавиша открывает мини-окно (`hub-capture--mini`).
- Пустая — плейсхолдер `text-muted`, кнопка «В корзину» недоступна. Фокус — рамка `accent`, стекло плотнее (`surface-hover`).
- Набирается — кнопка оживает; `#слово` становится меткой, она показывается тегом в строке подсказки.
- Добавлено — поле очищается, фокус остаётся; подсказка на 2,6 с: галочка `accent` + «В корзине — 6 неразобранных · Ctrl+Z — отменить» (`is-ok`), карточка «Корзина» вспыхивает (`is-bumped`). Без звуков и всплывающих окон.
- Пусто и Enter — мягкая подсказка «Напишите мысль и нажмите Enter», без ошибки.
- `hub-capture--compact` — та же строка в шапке оболочки приложения, подсказка скрыта.
- Никаких полей, дат и вопросов на этом шаге: всё решается при разборе.
