# Быстрый ввод — экран

Строка ввода в работе: на «Сегодня» и в мини-окне поверх других программ. Устройство самой строки — компонент «Строка быстрого ввода».

1. **Пустая** — курсор мигает, плейсхолдер «Мысль в корзину…», кнопка «В корзину» недоступна.
2. **Набирается** — кнопка оживает. `#слово` становится меткой. Подсказка меняется на «Enter — в корзину · Esc — очистить».
3. **Добавлено** — поле пустое, фокус в нём; подсказка с галочкой `accent` 2,6 с; карточка «Корзина» обновляет число и вспыхивает рамкой `accent` (`is-bumped`). `Ctrl+Z` возвращает текст в строку.
4. **Мини-окно** — `Ctrl+Alt+Пробел` (глобально, хаб свёрнут): по центру сверху маленькое окно 560px на плотном стекле `surface-strong` с размытием того, что под ним. Только строка и подсказка — ни карточек, ни меню. Enter — в корзину и закрыть; Esc — закрыть, текст не теряется до следующего открытия.
5. **Мини-окно: готово** — окно исчезает, на 1,5 с остаётся уведомление «В корзине — N».

Горячая клавиша для мини-окна настраивается; по умолчанию `Ctrl+Alt+Пробел` (уверенность средняя: проверить, что не занята в Windows и Obsidian).
