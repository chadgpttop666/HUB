# Телефон · разбор корзины

Разбор под большой палец: один элемент карточкой, решение — жестом.

| жест | действие | что видно под карточкой |
| --- | --- | --- |
| вправо | перенести → лист «Куда перенести» | подложка `accent-soft`, рамка `accent`, «Перенести…» |
| влево | удалить сразу, «Отменить» в уведомлении 4 с | подложка `danger-soft`, рамка `danger`, «Удалить» |
| вверх | отложить → лист сроков | подложка `surface-sunken`, «Отложить…» |

- Карточка `hub-swipe__card` едет за пальцем и слегка поворачивается (до 6°); подложка проявляется по мере сдвига. Порог — 30% ширины; не дотянул — карточка мягко возвращается (`duration-base`, `ease-out`). При «уменьшить движение» карточка не едет, а только меняется подложка.
- **Каждый жест продублирован кнопкой** внизу (удалить · отложить · перенести) — для доступности и для тех, кто не любит свайпы; подсказки жестов — строкой над кнопками.
- «Куда перенести» — нижний лист `hub-sheet` с приложениями из манифестов; последнее выбранное — первым и отмечено.
- Конкретная раскладка жестов — предложение (уверенность средняя): проверить на живом прототипе, не мешает ли «вверх» прокрутке длинного текста.
