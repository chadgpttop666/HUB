# Уведомление

Короткое сообщение внизу по центру о том, что уже произошло; само исчезает через 4 секунды.

```js
HubUI.toast("Удалено из корзины", { icon: "trash-2", action: "Отменить", onAction: restore });
HubUI.toast("Приложение установлено", { tone: "success", icon: "circle-check" });
```

- Плотное стекло `surface-strong`, форма пилюли, появляется подъёмом `duration-base`, уходит опусканием. Контейнер `hub-toasts` hub-ui.js создаёт сам, с `aria-live="polite"`.
- Тон (`accent`, `success`, `warning`, `danger`) красит **только значок**; текст всегда `text`.
- Действие одно и обратимое: «Отменить», «Открыть». Тихая кнопка `hub-toast__action` цвета `accent`.
- Одна строка, без точки в конце. Что-то требует решения — это диалог или экран, а не уведомление. Ошибки ввода показывают у поля, а не тут.
