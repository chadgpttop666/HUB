# Телефон · быстрый ввод

На телефоне мысль попадает в корзину тремя путями: строка на «Сегодня», виджет на рабочем столе и «Поделиться» из любой программы.

1. **Строка на «Сегодня»** — касание открывает клавиатуру; кнопка со стрелкой вверх оживает, когда есть текст; «Отправить» на клавиатуре делает то же.
2. **Добавлено** — поле очищается, клавиатура остаётся открытой, под строкой на 2,6 с: галочка `accent` и «В корзине — 6 · отменить».
3. **«Поделиться» → Хаб** — хаб регистрируется как получатель в системном меню «Поделиться». Открывается нижний лист `hub-sheet` поверх той программы: текст можно поправить, источник и ссылка подставляются сами, метки — тегами. «В корзину» — лист закрывается, человек остаётся там, где был.

Корзина не спрашивает пароль, чтобы положить мысль: запись дописывается зашифрованной, а прочитать её можно только после входа (уверенность средняя — проверить вместе с шифрованием на этапе 2).
