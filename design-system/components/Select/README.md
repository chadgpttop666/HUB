# Выпадающий список

Выбор одного варианта из известного списка: тема, папка, режим синхронизации.

```html
<label class="hub-select"><select aria-label="Тема">
  <option>Лес — тёмная</option><option>Туман — светлая</option>
</select></label>
```

- По умолчанию — родной `<select>`, обёрнутый в `hub-select`: работает с клавиатуры и на телефоне без кода. Стрелка рисуется маской, цвет `text-muted`.
- Когда у вариантов есть значки и пояснения справа, — своё меню `hub-menu` (см. «Меню»), открытое под полем.
- Состояния: наведение, фокус, ошибка `aria-invalid="true"` + подсказка, `disabled`.
- До 7 вариантов. Больше — поиск (`hub-search`) со списком. 2–3 коротких варианта — сегменты (`hub-segmented`, см. «Вкладки»).
