# Телефон · вход

Тот же вход, что на ПК, под палец: заставка → касание → пароль с открытой клавиатурой.

- Часы — `t-clock` на телефоне 72px (`hub-lock--phone`), приветствие 28px. Подсказка внизу: «Коснитесь, чтобы войти».
- После касания клавиатура открывается сразу; колонка поднимается (`hub-lock--kb`), часы уменьшаются до 56px.
- **Вход по отпечатку** — тихая кнопка под полем, системное окно Android (BiometricPrompt). Возможен, только если ключ данных можно хранить в Android Keystore под биометрией; решение за архитектурой (уверенность средняя). Без этого кнопки нет.
- Неверный пароль — как на ПК: линия и текст `danger`, значок, поле вздрагивает (без этого при «уменьшить движение»).
- Строка состояния Android — поверх фото, цвет `text` темы; полоска жестов внизу. Системный жест «назад» на заставке и пароле ничего не делает.
