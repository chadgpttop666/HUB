# Оболочка приложения

Как выглядит любое приложение, открытое внутри хаба: слева панель приложений, сверху строка ввода и статус, остальное — область приложения.

- **Панель приложений** `hub-rail` (стекло, 64px): «Сегодня», «Корзина» с числом (`hub-rail__badge` — `accent` / `on-accent`), разделитель, приложения в порядке из меню, внизу «Темы» и «Настройки». Текущее — `aria-current="page"` (`accent-soft`). Подписи — всплывающие и для чтения с экрана. `Alt+1…9` — приложение по номеру.
- **Шапка** `hub-shell__top`: компактная строка ввода (`hub-capture--compact`) — мысль можно кинуть, не выходя из приложения; справа статус синхронизации, `Ctrl K`, замок.
- **Область приложения** `hub-shell__main` — стекло, внутри — страница приложения в песочнице. Она прозрачная: фон, вуаль и стекло рисует хаб. Заголовок приложения — `hub-page-title`, разделы — вкладки.

Состояния:

1. **Открыто** — обычный вид.
2. **Окно 1024** — ширина панели та же, строка ввода сжимается, статус становится значком (`hub-sync--icon`), `Ctrl K` прячется.
3. **Нет сети** — `cloud-off` `text-muted`: работа идёт, всё уйдёт на Drive позже. Ничего не мигает.
4. **Конфликт** — статус-кнопка `warning`; по нажатию — карточка с файлом и «Сравнить версии» (экран конфликта — вторая очередь).
