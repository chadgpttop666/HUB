# Шаги

Где человек в коротком пошаговом процессе: первая настройка, подключение телефона.

```html
<ol class="hub-stepper" aria-label="Шаги">
  <li class="is-done">Имя</li>
  <li aria-current="step">Пароль</li>
  <li>Ключ</li>
</ol>
```

- Номер в кольце 24px, между шагами — черта `line-soft`. Пройденные — `is-done`: кольцо и цифра `accent`; текущий — `aria-current="step"`: заливка `accent`, цифра `on-accent`, подпись `text`; будущие — `text-muted`.
- 3–5 шагов, подписи — одним-двумя словами. Больше — значит, процесс надо упростить.
