# Живой поток

Рабочий прототип, пересобранный на hub.css: заставка → пароль → «Сегодня» → мысль в корзину. Кликните по экрану, затем любая клавиша; пароль — «лес».

Проверяет переходы и тайминги из раздела «Движение», клавиатурный путь без мыши, сообщения о неверном пароле, Caps Lock и английской раскладке, добавление в корзину с обновлением карточки. При системной настройке «уменьшить движение» сдвиги и масштаб пропадают, остаётся только смена прозрачности.
