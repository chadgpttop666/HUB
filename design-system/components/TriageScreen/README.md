# Разбор корзины

Один элемент крупно и под ним — приложения, которые могут его принять; разбирают с клавиатуры, по элементу за пару секунд.

- Сверху «Разбор корзины» (`hub-triage__title`) и счётчик «1 из 5» с полосой.
- **Элемент** — стекло, текст Jost light `font-size-3xl`, ниже — откуда и когда пришёл, метки.
- **Куда перенести** — плитки `hub-target` с цифрами 1–9. Список собирается из манифестов: приложение, объявившее `accepts`, само появляется здесь; надпись плитки — его `label` («Карточка для повторения»). Удалили приложение — плитка исчезла.
- Действия: «Отложить» `S`, «Удалить» `Del` (опасная), «Пропустить» `→` (тихая).

Состояния:

1. **Элемент** — плитка под курсором светлеет (`line`).
2. **Перенос** — нажатие цифры: плитка `is-chosen` (`accent-soft`, рамка `accent`), элемент улетает к ней и гаснет за `duration-slow` (`ease-in`), следующий поднимается снизу. Уведомление «Перенесено в «Повторение»» с «Отменить». Дальше приложение-получатель само решает, чем станет элемент.
3. **Отложить** — меню сроков под кнопкой: вечер, завтра утром, через неделю, своя дата.
4. **Удалено** — сразу, без диалога; «Отменить» в уведомлении 4 с.
5. **Пусто** — итог (сколько куда) и кнопка «На «Сегодня»» (`Esc`).

На телефоне то же самое свайпами: вправо — в первое приложение-получатель, влево — удалить, вниз — отложить (вторая очередь).
