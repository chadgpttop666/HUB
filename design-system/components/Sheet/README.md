# Нижний лист

Выбор или короткий ввод на телефоне, не уводящий с экрана: куда перенести, когда напомнить, «Поделиться» в корзину.

```html
<div class="hub-scrim"></div>
<div class="hub-sheet" role="dialog" aria-label="Куда перенести">
  <div class="hub-sheet__handle"></div>
  <h2 class="hub-sheet__title">Куда перенести</h2>
  <p class="hub-sheet__text">Приложения, которые принимают элементы корзины</p>
  <ul class="hub-list">…строки hub-row высотой 56…</ul>
</div>
```

- Плотное стекло `surface-strong`, верхние углы `radius-xl`, ручка `line` 32×4. Под листом — вуаль `hub-scrim` (`scrim-mid`).
- Появляется подъёмом за `duration-slow` (`ease-out`); закрывается свайпом вниз, касанием вуали или системным «назад».
- Внутри — заголовок `font-size-xl`, одна строка пояснения и список `hub-row` (56px) или поле с кнопками. Больше одного экрана содержимого — это уже отдельный экран.
- На ПК вместо листа — меню (`hub-menu`) или диалог.
