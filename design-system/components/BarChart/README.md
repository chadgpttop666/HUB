# Столбиковый график

Одна величина по дням или неделям для статистики приложений; одна серия, без легенды — заголовок называет, что посчитано.

```html
<figure class="hub-bars">
  <figcaption class="hub-bars__title">Повторено за 14 дней <small>всего 280</small></figcaption>
  <div class="hub-bars__plot" role="img" aria-label="Повторено по дням, от 0 до 38">
    <span class="hub-bars__axis">40</span><span class="hub-bars__axis hub-bars__axis--mid">20</span>
    <div class="hub-bars__col" style="--v:.55" tabindex="0" data-tip="Пн 17: 22"><span class="hub-bars__bar"></span><span class="hub-bars__x">17</span></div>
  </div>
  <table class="hub-sr">…те же числа таблицей…</table>
</figure>
```

Приложение передаёт: заголовок с итогом, верх шкалы (круглое число ≥ максимума) и для каждого столбца `--v` = значение / верх шкалы, подпись по оси и `data-tip` («Пн 17: 22»).

- Столбцы `accent`, тонкие (до 22px), между ними 2px, верх скруглён на 4px, низ стоит на базовой линии. Сетка — три линии `line-soft` с подписями 0 / середина / верх.
- Подсказка со значением — при наведении и фокусе с клавиатуры (Tab по столбцам). Сегодняшний день — подпись `text` полужирная.
- Обязательно таблица с теми же числами для чтения с экрана (`hub-sr`).
- Не делать: две шкалы, несколько серий разными цветами, значения на каждом столбце, цветные плашки. Нужно сравнить две величины — два графика друг под другом.
