# Пример приложения: «Повторение»

Проверка набора: экран приложения повторения собран только из классов hub.css, типографских стилей `t-*` и токенов — ни одного своего цвета или шрифта.

Что использовано: `hub-page-title`, вкладки `hub-tabs` с числом, `hub-meter` + `hub-progress`, стекло `hub-glass`, теги (нейтральный и `--warning`), стиль `t-display` для вопроса и `t-body-l` для ответа, кнопки (основная `--lg` с `kbd`, обычные, тихая), `hub-list--divided` с `hub-row`, таймер `hub-timer` и шаги `hub-steps`, сегменты, `hub-bars`, `hub-table`, `hub-number`, `hub-spinner`, `hub-empty`.

Состояния: вопрос → ответ с оценками (`1–4`, «Хорошо» — основная, под каждой — следующий интервал) → статистика → учебный блок → «На сегодня всё повторено».

Своё у приложения — только раскладка (сетка из двух колонок) и тексты. Если приложению не хватает компонента, его добавляют в hub.css, а не рисуют в приложении.
