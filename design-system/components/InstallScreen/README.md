# Установка приложения

Перетащил папку или zip в хаб → посмотрел, что приложение просит → «Установить».

1. **Перетаскивание** — пока файл над окном, весь экран становится целью `hub-drop`: пунктир `accent`, плотное стекло, «Отпустите, чтобы установить» и имя файла. Отпустил не туда — ничего не происходит.
2. **Права** — диалог: значок, имя, версия, откуда и размер; список того, что приложение просит, из манифеста: свои данные (всегда), приём из корзины (с подписью из `accepts`), уведомления, доступ в сеть (с адресом и тегом `warning`). Ниже — чего у приложения не будет никогда. «Установить» — основная, Enter.
3. **Установлено** — где появилось: меню, разбор корзины, телефон. «Открыть» или «Готово».
4. **Ошибка** — хаб ничего не ставит и перечисляет причины словами, по одной на строку (`hub-hint--error`): нет поля, внешний скрипт без заявки и т. п.; «Показать манифест» и подсказка исправить по APP_SPEC.md.

Обновление уже установленного — тот же диалог с пометкой «было 0.1.0 → станет 0.2.0» и списком новых прав (предложение).
