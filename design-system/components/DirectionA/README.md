# Направление А · Тихий центр

Доработанный прототип: всё по центру, строка ввода первой, карточки приложений сеткой под ней. **Выбрано (пока): на нём собраны все экраны ПК; телефон повторяет его порядок — строка ввода, потом карточки.**

- За: ближе всего к принятым решениям; глаз идёт сверху вниз — мысль, потом дела; сетка карточек растёт до 8+ без переделки; одинаково на 1440 и 1024.
- Против: самое «ожидаемое»; фото видно только по краям и сквозь стекло.
