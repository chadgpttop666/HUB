# Иконки

Один линейный набор — Lucide (лицензия ISC): у каждой иконки сетка 24, линия 1.6, скругленные концы, цвет — `currentColor`.

- В разметке: `<i data-icon="inbox"></i>` — hub-ui.js заменит на `<svg class="hub-icon">`. В коде: `HubUI.icon("inbox", {size: 16})`.
- Размеры: 16 в кнопках, тегах и строках, 20 по умолчанию, 24 крупно, 40 в пустом состоянии (линия 1.2).
- Цвет — цветом текста рядом: `text-muted` для вспомогательных, `accent` только у значка строки ввода и «добавлено», `success` / `warning` / `danger` — только для состояний.
- Иконка без подписи на кнопке — обязательно `aria-label` у кнопки.
- Встроено 103 иконок (список на превью). Нужна другая — берётся из того же Lucide (lucide.dev) тем же стилем и добавляется в hub-ui.js; рисовать свои и брать из других наборов нельзя.
