# Темы

Тема — это фото плюс набор значений токенов; разметка и hub.css одни на все темы.

- **Лес — тёмная** (`data-theme="dark"`) — основная, на фото леса в тумане.
- **Туман — светлая** (`data-theme="light"`) — на светлом фото; тёмный текст и белая вуаль.
- **Без фото** (`data-theme="solid"`) — сплошной `bg`, стекло становится плотными поверхностями, вуали прозрачные.

Хаб ставит `data-theme` на `<html>` хаба и каждого приложения и передаёт фото через `--hub-photo`. Как собрать новую тему из любого фото — раздел «Темы».

Нельзя: менять цвета в обход токенов, «подкрашивать» отдельное приложение, класть текст прямо на фото без вуали или стекла.
