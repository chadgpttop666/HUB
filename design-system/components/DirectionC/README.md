# Направление В · Горизонт

Строка ввода стоит посередине экрана, как линия горизонта на фото; часы и дата — маленьким блоком слева сверху; карточки — одна полка у нижнего края.

- За: самый «воздушный» вариант, центр экрана свободен для фото; строку ввода видно лучше всего; после экрана входа почти ничего не прыгает — часы просто уезжают в угол.
- Против: в полке помещаются 4 карточки, остальное — прокруткой вбок («ещё 5»); карточкам меньше места по высоте; полка у нижнего края хуже работает на светлых фото с тёмной землёй (нужна более сильная вуаль снизу).
