# Пустое состояние

Что показать, когда показывать нечего: всё сделано, ничего не найдено, приложение ещё без данных.

```html
<div class="hub-empty">
  <i data-icon="inbox" class="hub-empty__icon"></i>
  <h2 class="hub-empty__title">Корзина пуста</h2>
  <p class="hub-empty__text">Всё разобрано. Новая мысль — Ctrl+Пробел из любой программы.</p>
  <div class="hub-empty__action"><button class="hub-btn">На «Сегодня»</button></div>
</div>
```

- Значок 40 с линией 1.2 `text-muted`, заголовок Jost light `font-size-3xl`, текст `text-muted` до 40 знаков в строке, не больше одной кнопки.
- Заголовок — факт («Корзина пуста»), текст — что дальше. Тон спокойный: без восклицаний, конфетти и «Ура!».
- «Ничего не найдено» подсказывает исправление (раскладка, другое слово).
