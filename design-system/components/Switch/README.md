# Переключатель

Включает или выключает настройку сразу, без кнопки «Сохранить».

```html
<label class="hub-switch"><input type="checkbox" role="switch" checked><span>Синхронизировать в фоне</span></label>
```

- Выключен — дорожка с рамкой `line`, бегунок `text-muted`; включён — дорожка `accent`, бегунок `on-accent` справа. Бегунок едет `duration-base`.
- Подпись справа и называет то, что включается («Синхронизировать в фоне»), а не «Вкл/Выкл».
- Состояния: наведение, фокус (кольцо `focus`), `disabled` — с объяснением рядом, почему недоступно.
- Если изменение нужно подтвердить или оно применяется позже — чекбокс в форме с кнопкой.
