# Карточка приложения

Карточку на «Сегодня» даёт приложение; форма у всех одна и та же, наполнение — четыре поля.

```html
<article class="hub-card">
  <div class="hub-card__app"><i data-icon="layers"></i><span>Повторение</span></div>
  <div class="hub-card__main">12 карточек к сроку</div>
  <p class="hub-card__note">2 темы просели: логика, право</p>
  <div class="hub-card__action"><button class="hub-btn hub-btn--sm">Начать</button></div>
</article>
```

Приложение передаёт: название и значок (из манифеста), **главную строку** (что сейчас важно, с числом), **пояснение** (одна строка контекста), и **либо** одну кнопку (глагол), **либо** короткий список с отметками (до 4 пунктов, остальное — «ещё N» в `hub-card__more`).

- Главная строка — Jost `font-size-2xl`; длинная обрезается на 2 строках многоточием. Пояснение — `font-size-sm`, `text-muted`, тоже 2 строки максимум. Карточки в ряду одной высоты, кнопка прижата к низу.
- Всё сделано — `hub-card--done`: главная строка `text-muted` («Всё повторено»), кнопки нет.
- Пока данные грузятся — те же места заняты `hub-skeleton`.
- Новое в корзине — `is-bumped`: рамка вспыхивает `accent` и карточка чуть подпрыгивает.
- Сетка — `hub-cards` (колонки от 240px). Перетаскивать и менять размер нельзя.

Не класть в карточку: таблицы, графики, больше одной кнопки, цветные плашки, иконки-эмодзи.
