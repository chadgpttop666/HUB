# Командная строка

`Ctrl K` из любого места: найти приложение, выполнить команду или открыть запись — не трогая мышь.

- Окно `hub-dialog hub-command` сверху по центру (12% высоты), 640px; под ним вуаль `scrim-mid` с размытием. Поле поиска — Jost light 22px, курсор уже в нём.
- Пустой запрос — «Недавнее» и «Команды». С запросом — группы «Приложения», «Записи», «Команды»; совпадение выделено `accent` (`<mark>`), первая строка подсвечена (`is-active`). Записи ищут приложения через Hub API и показывают, из какого они приложения.
- Клавиши: ↑/↓ — выбор, Enter — открыть, Tab — к следующей группе, Esc — закрыть. Подписаны в подвале окна.
- **Ничего не нашлось**: если запрос в другой раскладке что-то значит, хаб предлагает исправленный вариант первым; вторым — «В корзину как мысль» (`Ctrl+Enter`), чтобы набранное не пропало.
- До 8 строк на группу; остальное — «ещё N» в конце группы.
