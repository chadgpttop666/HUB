# Первая настройка

Один раз, при первом запуске: четыре шага на плотном стекле поверх размытого фото, по одному решению на экран.

- Сверху — шаги `hub-stepper`: пройденные — цифра `accent` в кольце, текущий — заливка `accent`, будущие — `text-muted`. Назад можно всегда; вперёд — основная кнопка с Enter.
1. **Имя** — «Как к вам обращаться?», одно поле.
2. **Пароль** — дважды; совет про длинную фразу вместо правил «цифра + символ»; несовпадение показывается у второго поля, «Дальше» недоступна. Прямо сказано, что пароль не восстановить.
3. **Ключ восстановления** — 8 групп по 4 знака (`hub-key`, без похожих 0/O, 1/I), крупно, с разрядкой; «Распечатать». «Дальше» недоступна, пока не отмечено «Я записал ключ и убрал бумагу». Копировать в буфер не предлагается — ключ не должен попасть в облако.
4. **Google Drive** — что хаб увидит и чего не увидит, тремя строками; «Подключить» открывает окно входа Google; «Позже — только на этом ПК» не запрещает подключить потом.
5. **Готово** — итог тремя галочками и переключатель «Открывать хаб при входе в Windows» (включён). Дальше — сразу «Сегодня», без повторного ввода пароля.

На телефоне шаги те же, но ключ не показывается заново: телефон подключается к уже настроенному хабу (решить на этапе 2).
