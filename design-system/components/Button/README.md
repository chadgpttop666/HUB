# Кнопка

Действие одним нажатием; по умолчанию — обычная (контур), основная — не больше одной на экран.

```html
<button class="hub-btn hub-btn--primary" type="button">Начать</button>
<button class="hub-btn" type="button"><i data-icon="plus"></i>Добавить</button>
<button class="hub-btn hub-btn--quiet hub-btn--icon" aria-label="Ещё"><i data-icon="ellipsis"></i></button>
```

- **Основная** `--primary` — то, ради чего экран: «Начать», «Показать ответ», «Войти». Заливка `accent`, текст `on-accent`.
- **Обычная** без модификатора — всё остальное. Контур `line`; при наведении рамка и текст `accent`.
- **Тихая** `--quiet` — второстепенное рядом с основной: «Пропустить», «Отмена», меню «ещё».
- **Опасная** `--danger` — только необратимое: «Удалить». Подтверждение — в диалоге или отменой в уведомлении.
- `--glass` — кнопка, которая лежит прямо на фото (шапка «Сегодня»).
- Размеры `--sm` (32, в карточках и таблицах), обычная (36), `--lg` (44 — телефон и крупные действия); `--icon` — квадратная, только с `aria-label`.
- Состояния: `:hover`, `:focus-visible` (кольцо `focus` 2px с отступом 2px), `disabled` / `aria-disabled="true"` (`opacity-disabled`), `aria-busy="true"` (кружок загрузки вместо значка, нажатия не принимаются).
- Горячая клавиша — `<kbd class="hub-kbd">` внутри кнопки, после текста.

Текст — глагол, с прописной, без точки: «Разобрать», а не «Разбор». Не больше двух слов.
