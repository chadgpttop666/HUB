# Темы

Галерея тем и настройка одной темы; новая тема собирается из любого фото по правилу из раздела «Темы».

1. **Галерея** — `hub-themes`: карточки `hub-theme` с живым кусочком хаба внутри (каждая со своим `data-theme`), имя и «тёмная · рассвет». Текущая — рамка `accent` и галочка (`aria-checked="true"`). Наведение показывает тему на весь экран, Enter — применяет. Последняя карточка — «Новая тема из фото» (пунктир).
2. **Настройка** — слева форма, справа вход и «Сегодня» в этой теме, меняются сразу:
   - фото: заменить, положение;
   - вуаль: посчитанные значения и проверка контраста — словами, со значком;
   - акцент: кружки `hub-swatch`; цвет, который не проходит контраст в этой теме, недоступен, и подсказка говорит почему;
   - шрифт крупного текста: Jost / Manrope / системный;
   - приветствие с `{часть дня}` и `{имя}` и примером.
3. **Новая из фото** — после перетаскивания фото: какая основа выбрана и почему, вуаль, проверка контраста; если вуаль вышла сильной — предупреждение `warning` и «Сдвинуть фото». Название и «Сохранить тему».

Отдельные приложения свою тему не получают — одна тема на всё.
