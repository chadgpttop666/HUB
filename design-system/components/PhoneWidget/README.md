# Телефон · виджет на рабочем столе

Самый короткий путь мысли в корзину на телефоне: касание виджета → текст → «Отправить».

- **4×2** — строка «Мысль в корзину…» и три числа дня: корзина, к повторению, план. **4×1** — только строка. Размеры по сетке Android; при растягивании меняется только ширина строки.
- Касание строки открывает окно ввода поверх рабочего стола (прозрачная активность Android): нижний лист со строкой `hub-capture--phone` над клавиатурой. Хаб целиком не открывается и пароль не спрашивается (см. «быстрый ввод»).
- «Отправить» — окно закрывается, в виджете на 2 с строка «✓ В корзине — 6», потом снова числа. Касание чисел открывает хаб на нужном разделе (после пароля).
- Цвета — плотное стекло темы: `surface-strong`, строка `surface-sunken`, значок `accent`. Размытие под виджетом Android не даёт, поэтому стекло здесь непрозрачное.
- Виджет рисуется нативно (Jetpack Glance / RemoteViews), не веб-страницей: значения берутся из токенов текущей темы при её смене (уверенность высокая, что HTML в виджете невозможен; как именно передавать тему — решить на этапе 2).
- Значок приложения «Хаб» на рабочем столе — временный (лампочка на `accent`): знака пока нет.
