# Чекбокс

Отметка «сделано / выбрано»; вся строка с текстом — одна цель для нажатия.

```html
<label class="hub-check hub-check--done"><input type="checkbox" checked><span>балкон</span></label>
```

- Квадрат 18 с рамкой `line`; отмечен — заливка `accent`, галочка `on-accent`; `indeterminate` — черта.
- `hub-check--done` — для списков дел: отмеченный пункт становится `text-muted` и зачёркнутым, но остаётся читаемым.
- Состояния: наведение (рамка `text`), фокус (кольцо `focus`), ошибка `aria-invalid="true"` (рамка `danger`, рядом — подсказка словами), `disabled`.
- Для «включить / выключить настройку» — переключатель, а не чекбокс.
