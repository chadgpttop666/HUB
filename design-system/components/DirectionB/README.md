# Направление Б · Страница дня

Всё в одной колонке слева, как страница личного дневника: дата, приветствие, строка ввода, список дел по приложениям строками, без карточек. Правая половина отдана фото.

- За: самое личное и спокойное; фото видно больше всего; текст читается как список, а не как дашборд.
- Против: строка на приложение даёт меньше места, чем карточка (список с отметками не помещается); 8+ приложений — длинный список; на 1024 колонка занимает почти всё.
