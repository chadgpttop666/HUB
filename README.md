# Хаб

Личная оболочка для ПК (позже — и телефона): строка «мысль в корзину», экран «Сегодня», разбор корзины по приложениям и сами приложения — каждое в своей песочнице. Замысел и план — в [диздоке](docs/design-doc.md), вид — в [дизайн-системе](design-system/README.md).

**Сейчас: этап 3** — приложения от нейросети: [APP_SPEC.md](APP_SPEC.md) прикладывается к запросу «сделай мне приложение для…», результат ставится перетаскиванием папки или zip в окно хаба; календарь; свои темы из фото. Что сделано и где я не уверен — [docs/stage-3.md](docs/stage-3.md). Раньше: оболочка, корзина, «Повторение» ([этап 1](docs/stage-1.md)); пароль, шифрование, синхронизация через Google Drive, Android ([этап 2](docs/stage-2.md)).

## Как получить хаб на Windows

1. Вкладка **Actions** репозитория → последний успешный запуск «Хаб — проверка и сборка» → артефакт **hub-windows** → внутри `Хаб_…_x64-setup.exe` (для телефона — **hub-android**, `Хаб.apk`).
2. Установить (ставится для текущего пользователя, без прав администратора). SmartScreen может предупредить: установщик не подписан — «Подробнее» → «Выполнить в любом случае».
3. Перенести старые данные «Повторения»: в старом `repetition.html` нажать «⇩ Экспорт» → в хабе открыть «Повторение» (`Alt+1`) → «⇧ Импорт» → выбрать скачанный `theory-backup-….zip` → «Заменить оба».

При первом запуске хаб попросит пароль и покажет ключ восстановления — его нужно записать на бумагу. Данные лежат в `%APPDATA%\local.hub.desktop\data` — каждая запись отдельным файлом, зашифрованным ключом данных.

Телефон: поставить `Хаб.apk` → «Подключить к существующему» → войти в тот же Google → пароль хаба (на ПК синхронизация должна быть уже включена).

## Как пользоваться

| где | что |
| --- | --- |
| везде | `Ctrl+Alt+Пробел` — хаб из любой программы, курсор в строке ввода; `Ctrl+L` — запереть |
| хаб | `Ctrl+Пробел` или `/` — к строке ввода; `Alt+1…9` — приложение по номеру |
| строка ввода | `Enter` — в корзину, `#слово` — метка, `Ctrl+Z` в пустой строке — отменить последнее |
| разбор корзины | `1–9` — перенести в приложение, `S` — отложить, `Del` — удалить, `← →` — листать, `Esc` — выйти |

## Устройство

```
ui/                 оболочка: «Сегодня», разбор, панель приложений, настройки (HTML + JS-модули, без сборщика)
runtime/            то, что хаб вставляет в каждое приложение: hub-app.js (Hub API и подмены localStorage/indexedDB), app.css
apps/repetition/    «Повторение»: repetition.html на токенах темы + приём из корзины и карточка «Сегодня»
apps/calendar/      «Календарь» — написан по APP_SPEC.md
templates/app/      шаблон приложения, который вставляется в APP_SPEC.md
APP_SPEC.md         файл правил для нейросети (собирается: node scripts/app-spec.mjs)
design-system/      набор «Хаб» как есть: токены, hub.css, hub-ui.js, шрифты, темы, описания компонентов
src-tauri/          ядро на Rust (Tauri 2): зашифрованные файлы данных, пароль и ключи, синхронизация через rclone,
                    протокол hubapp:// для песочниц, уведомления, Ctrl+Alt+Пробел
scripts/            build-ui.mjs — собирает dist/ для Tauri; dev-server.mjs — хаб в обычном браузере;
                    fetch-rclone.mjs, build-rclone-android.sh, patch-android.mjs, sign-apk.sh — rclone и Android
tests/run.mjs       сквозные тесты в Chromium; tests/tauri-e2e.mjs — два окна Tauri через WebDriver
tools/sandbox-probe приложение-проверка: пытается выбраться из песочницы и проверяет Hub API
tools/rclone-check  этап 0: как rclone ведёт себя при синхронизации, конфликте и удалении
docs/               диздок, Hub API, заметки по этапу 1
```

Приложение видит только [Hub API](docs/hub-api.md): свои данные, корзину, тему, уведомления. Страница приложения открыта в `iframe` без `allow-same-origin` и с CSP без сети — ни хаба, ни ядра, ни интернета, ни чужих данных.

## Разработка

Нужны Node 20+ и (для ядра) Rust + системные библиотеки Tauri.

```bash
npm install
```

Хаб в обычном браузере (ядро — заглушка: данные в `localStorage` страницы, Blob — в памяти):

```bash
npm run dev
```

Сквозные тесты (нужен пакет `playwright` и Chromium):

```bash
npm test
```

rclone для своей платформы (нужен для сборки ядра — он встраивается в хаб):

```bash
node scripts/fetch-rclone.mjs
```

Тесты ядра, включая синхронизацию с настоящим rclone:

```bash
cd src-tauri && HUB_RCLONE=$PWD/binaries/rclone-x86_64-unknown-linux-gnu cargo test
```

Окно Tauri у себя:

```bash
npx tauri dev
```

Установщик для Windows (на Windows):

```bash
npx tauri build
```
