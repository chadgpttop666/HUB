# Хаб

Хаб — личное приложение для Windows и Android. В нём можно быстро записать мысль, разобрать дела, запланировать день и вернуться к материалам для повторения. На экране **«Сегодня»** видны карточки подключённых приложений. Встроенные инструменты можно дополнить своими, а данные между устройствами синхронизировать через личный Google Drive.

[Скачать Хаб для Windows и Android](https://github.com/chadgpttop666/HUB/releases/latest)

## Что можно делать

- **Корзина.** Запишите мысль сразу, а при разборе перенесите её в нужное приложение, отложите или удалите. Например, «завтра в 16:00 консультация» можно отправить в календарь как событие.
- **Повторение.** Храните конспекты и вопросы, распределяйте материал по темам и возвращайтесь к нему на повторении. Заметки и архивы «Повторения» можно перетащить в его окно на ПК.
- **Календарь.** Переключайтесь между лентой дня и неделей по часам. Импортируйте расписания из ответа нейросети, проверяйте пересечения и дубли перед сохранением. Для события можно выбрать тихое уведомление, обычное или будильник.
- **Своё рабочее пространство.** Выберите тему, настройте порядок приложений и добавьте свой инструмент. На Windows Хаб может запускаться при входе и оставаться в трее.

## Установка и обновление

| Платформа | Установка | Обновление |
| --- | --- | --- |
| Windows x64 | Запустите `Hub-…-windows-x64-setup.exe`. Хаб устанавливается для текущего пользователя. | Откройте **Настройки → Обновления Хаба → Обновить Хаб**. Хаб сверит установщик с SHA-256 из GitHub Releases, применит обновление и откроется снова. |
| Android ARM64 | Откройте `Hub-…-android-arm64.apk` на телефоне и подтвердите установку. | Откройте **Настройки → Обновления Хаба → Проверить обновления**. При запросе разрешите Хабу устанавливать приложения, вернитесь и снова нажмите **«Установить»**. |

Файлы для обеих платформ публикуются в разделе [GitHub Releases](https://github.com/chadgpttop666/HUB/releases/latest).

При первом запуске выберите **«Новый хаб»** и задайте пароль. Хаб покажет ключ восстановления. Сохраните его отдельно от устройства. Подключение Drive можно отложить и начать пользоваться Хабом локально. Если данные уже есть на другом устройстве, выберите **«Подключить к существующему»**.

Старую базу «Повторения» можно перенести через ZIP. В прежнем приложении нажмите **«Экспорт»**, затем выберите архив через **«Импорт»** в «Повторении» внутри Хаба.

## Как добавить своё приложение

### С помощью нейросети

1. На ПК откройте **Настройки → Приложения → Как создать приложение с нейросетью**.
2. Скачайте спецификацию и нажмите **«Показать и скопировать запрос»**. Приложите спецификацию к чату и опишите нужные экраны, данные и действия. Например, «трекер чтения, который принимает название книги из Корзины и показывает текущую книгу на экране “Сегодня”». [APP_SPEC.md](APP_SPEC.md)
3. Сохраните ZIP из ответа. Перетащите его в **Настройки** на ПК или выберите **Из zip** в разделе **«Приложения»**. Хаб покажет состав пакета и запрошенные сетевые адреса. Проверьте их и подтвердите установку.

### Написать самому

В папке приложения нужны `manifest.json` и `index.html`. Добавьте рядом свои JS, CSS и изображения. Хаб открывает страницу и подставляет стили текущей темы и объект `window.hub`. Готовую папку можно выбрать через **Настройки → Приложения → Из папки** или упаковать в ZIP. [Рабочий шаблон](templates/app) · [Hub API](docs/hub-api.md)

- `hub.data` хранит записи и файлы в пространстве приложения. Используйте отдельные ключи для отдельных записей, например `notes/<id>`.
- `hub.inbox` принимает мысли из Корзины, если приложение объявило `accepts` в манифесте.
- `hub.today` передаёт данные для карточки на экране **«Сегодня»**, если в манифесте включён `card`.
- `hub.notify` отправляет уведомление при вызове. Календарные напоминания по расписанию обслуживает встроенный календарь через ядро Хаба.

Для обновления своего приложения установите новый пакет с тем же `id`. Пакет и данные, записанные через Hub API, появятся на втором устройстве после синхронизации. Сетевые запросы приложения ограничены адресами из `permissions.network`.

**Своя тема.** В **Настройки → Тема** есть редактор и запрос для нейросети. Пакет темы содержит `theme.json` и, при необходимости, фоновое изображение. ZIP устанавливается из настроек на ПК. [Дизайн-система и формат темы](design-system/README.md)

## Как подключить Google Drive

**На первом устройстве**

1. В своём проекте Google Cloud включите Google Drive API. [Открыть Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com)
2. Настройте экран согласия в Google Auth Platform. Если проект в режиме тестирования, добавьте свой Google-аккаунт в список тестовых пользователей. Создайте OAuth-клиент типа **Desktop app** и сохраните **Client ID** и **Client Secret**. [Открыть список OAuth-клиентов](https://console.cloud.google.com/auth/clients)
3. В Хабе откройте **Настройки → Синхронизация**, вставьте оба значения и нажмите **«Подключить Google Drive»**. Подтвердите доступ в браузере и дождитесь первого обмена.

**На втором устройстве**

1. На первом устройстве откройте **Настройки → Синхронизация → Показать ключи Google Drive**. После ввода пароля Хаба можно скопировать сохранённую пару.
2. При первом запуске на втором устройстве выберите **«Подключить к существующему»**. Введите те же Client ID и Client Secret, войдите в тот же аккаунт Google и введите пароль Хаба.

Хаб запрашивает доступ `drive.file` и работает со своей папкой **Hub** в Google Drive. Для подключения к существующим данным используйте прежнюю пару OAuth и тот же Google-аккаунт.

## Как работает синхронизация

1. **Запись на устройство.** Ядро на Rust сохраняет каждую запись приложения отдельным зашифрованным файлом. Правки, ожидающие отправки, лежат в зашифрованной очереди и переживают перезапуск.
2. **Обмен через Drive.** У каждого устройства свой журнал правок. Встроенный rclone отправляет изменения и читает новые части журналов других устройств. Содержимое и имена файлов в `Hub/crypt/` шифруются. Файл `Hub/keys.json` содержит зашифрованную копию ключа данных, которую можно открыть паролем Хаба или ключом восстановления. Для хранения и обмена используется ваш Google Drive. Синхронизацию выполняют сами устройства.
3. **Применение правок.** Изменения разных записей сливаются. Если два устройства изменили один ключ, ядро выбирает версию по времени правки. Конфликты, которые Хаб сохранил при встрече с ещё не отправленной локальной правкой, видны в настройках.
4. **Когда ждать результат.** Отправка обычно начинается после короткой паузы в редактировании, примерно через две секунды. Открытый Хаб проверяет Drive примерно раз в 30 секунд и после возвращения в окно. Если Android приостановит приложение, отправка может продолжиться при следующем открытии.

**Что проверить при задержке.** В **Настройки → Синхронизация** сравните **«Последнюю отправку»** на исходном устройстве и **«Последнее получение»** на втором. Там же видны очередь, текущий этап, причина сбоя и время автоповтора. Кнопка **«Синхронизировать»** запускает проверку вручную. Если Drive отклонил доступ, проверьте аккаунт Google, прежнюю пару OAuth и включение Drive API в Google Cloud.

### Синхронизация папок

В **Настройки → Синхронизация → Помеченные папки** можно добавить папку с файлами, например хранилище Obsidian. Перед первой синхронизацией этой папки Хаб показывает пробный прогон. На втором устройстве нужно выбрать локальную папку для этих файлов. На Android приложению понадобится системное разрешение **«Доступ ко всем файлам»**.

Файлы в такой папке остаются доступны обычным программам на устройстве. На Drive rclone хранит их зашифрованными. Двусторонний обмен идёт через rclone bisync. Если синхронизация приведёт к массовому удалению файлов, Хаб приостанавливает обмен для этой папки и предлагает проверить изменения. При доступном Drive Хаб создаёт ежедневные снимки и хранит до 30 последних снимков каждого набора данных.

## Календарь и напоминания

В **Календарь → Импорт** скопируйте промпт и приложите расписания в чате с нейросетью. К запросу можно добавить выбранные записи из календаря, в том числе перенесённые из Корзины. Вставьте полученный ответ или загрузите его файлом, проверьте даты и выберите нужные строки. Последний импорт можно отменить.

На Android выдайте разрешения на уведомления и, для режима будильника, на точные будильники. На Windows напоминания работают, пока Хаб запущен, в том числе в трее.

## Устройство и разработка

Хаб работает на Tauri 2. Оболочка загружает приложения в изолированные iframe. Приложения обращаются к своим данным через Hub API. Ключами, шифрованием и подключением Drive управляет ядро.

| Папка | Что внутри |
| --- | --- |
| `ui/` и `runtime/` | Оболочка, изоляция приложений, Hub API и подключение темы. |
| `apps/` и `templates/app/` | Встроенные «Повторение» и «Календарь», шаблон для нового приложения. |
| `src-tauri/` | Ядро Rust, хранилище, rclone, системные окна и напоминания. |
| `design-system/` | Токены, компоненты, шрифты и темы. |
| `tests/` | Сквозные проверки интерфейса и обмена между двумя окнами Tauri. |

Для браузерного режима нужны Node.js и npm. Для нативной сборки дополнительно нужны Rust и системные библиотеки. [Требования Tauri](https://v2.tauri.app/start/prerequisites/)

```bash
npm ci
npm run dev
```

Браузерный режим использует тестовое хранилище. Для запуска нативного Хаба скачайте rclone для своей платформы и выполните `npx tauri dev`. На Windows `npx tauri build` собирает установщик.

```bash
node scripts/fetch-rclone.mjs
npx tauri dev
```

Проверки интерфейса и Rust можно запустить отдельно.

```bash
npm install --no-save playwright@1.49.1
npx playwright install chromium
npm test
node scripts/build-ui.mjs
cd src-tauri
cargo check --locked
cargo test --locked
```

На Windows инструменты разработчика доступны по F12 или через **Настройки → Инструменты разработчика → Открыть DevTools**. Для замера задержек запишите переключение экранов на вкладке **Performance**.

Для тестов обмена с настоящим rclone передайте путь к бинарнику в переменной `HUB_RCLONE`. Сборка по тегу публикует установщики Windows и Android и проверяет постоянный сертификат Android. [Настройки CI](.github/workflows/build.yml)
